## What the plan said

BIT-49.16 told migrate to `os.MkdirAll(data, 0o755)` before `os.MkdirTemp`, because "a first migration may run before the data dir exists". Its commit sequence `Lstat`s only the shared feedback/retro destinations before moving anything.

## What happened

`store.Dir()` already creates the data dir, so the extra `MkdirAll` was redundant and was left out. The project dir (`store.ProjectDir(code)`) was added to the same `Lstat` preflight. Without it, a clash on the project dir would only show up after the shared notes had already moved, which breaks the "changes nothing at all" promise. Verify enumerates source files with the same filters the copy uses (`.md`, or `-proposals.md` for retro).
