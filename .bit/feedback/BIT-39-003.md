What was discovered: this project runs two hooks configured in
`.claude/settings.json`, and both catch an unused import without the plan
having to name it.

- `PostToolUse` on `Edit|Write` runs `.claude/hooks/post-edit-go.sh`, which
  runs `golangci-lint run` after every `.go` edit and returns its output as
  `additionalContext` with "Go checks failed after editing $fp — fix before
  continuing."
- `Stop` runs `.claude/hooks/stop-go.sh`, which runs `just lint` and
  `just test` whenever `.go` files are dirty and returns
  `{"decision":"block"}` with "Go checks failed — do not stop until these are
  fixed."

An unused `context` import fails `go build`, so it fails both `golangci-lint`
and `just test`. The user's position is that the omission is therefore not a
problem, and that raising it three times — twice as an offer to record it —
was the thing that needed correcting.
